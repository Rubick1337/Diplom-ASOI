# Функциональные требования системы

---

## 1. Управление пользователями

### 1.1 Регистрация и аутентификация

- Регистрация по email и паролю: система проверяет уникальность email и username, пароль хранится в зашифрованном виде
- Вход через Google OAuth2 и GitHub OAuth2: при первом входе через OAuth автоматически создаётся учётная запись
- После успешного входа пользователю выдаётся пара токенов: краткосрочный access-токен и долгосрочный refresh-токен, хранящийся в HttpOnly cookie
- Обновление access-токена происходит автоматически по истечении срока без повторного входа
- Выход из системы инвалидирует refresh-токен

### 1.2 Профиль пользователя

- Личная статистика пользователя:
  - Общее количество решённых задач по программированию
  - Общее количество пройденных теоретических тестов
  - Процент успешных решений от всех попыток
  - Среднее время выполнения кода по принятым решениям
  - Текущий рейтинг и накопленный опыт
- История решённых задач: список задач, пройденных хотя бы раз успешно, с датой, языком и временем выполнения
- История пройденных тестов: список тестов с датой прохождения, результатом в процентах и лучшим результатом
- Список задач и тестов, созданных пользователем
- Список поданных жалоб с их текущим статусом
- Редактирование профиля: изменение имени пользователя и аватара

### 1.3 Роли

| Роль | Описание |
|---|---|
| Пользователь | Стандартный доступ: решение задач и тестов, соревнования, сообщество |
| Администратор | Модерация задач и жалоб |
| Владелец | Полный доступ к аналитике платформы |

## 2. Задачи по программированию

### 2.1 Создание задачи

- Пользователь заполняет основные поля: название, описание, тема, уровень сложности от 1 до 10
- Указывается функция для реализации: её имя, список параметров с названиями и типами данных
- Добавляются тест-кейсы: для каждого кейса задаются входные аргументы и ожидаемый результат
- Перед публикацией выполняется автоматическая верификация: система проверяет, что тест-кейсы корректны и не противоречат друг другу
- Задача сохраняется как черновик до прохождения верификации

### 2.2 Просмотр и фильтрация задач

- Список задач отображается постранично с настраиваемым количеством элементов
- Доступна фильтрация по теме, уровню сложности и языку программирования
- Доступна сортировка: по дате добавления, по сложности, по количеству решений
- Кнопка «Случайная задача» — мгновенный переход к произвольной задаче с учётом активных фильтров

### 2.3 Решение задачи

- Рабочее пространство состоит из: редактора кода, панели с условием задачи, терминальной панели с результатами
- Редактор поддерживает 9 языков программирования: JavaScript, TypeScript, Python, C++, C, C#, Java, PHP, CoffeeScript — с подсветкой синтаксиса для каждого
- Переключение языка сбрасывает текущие результаты и логи
- Пользователь запускает код нажатием кнопки; код выполняется в изолированном Docker-контейнере с ограничением памяти и без доступа к сети
- По завершении выполнения отображается результат по каждому тест-кейсу отдельно: статус (пройден / не пройден), фактический вывод программы, ожидаемый вывод и время выполнения
- При наличии ошибок компиляции или исполнения отображается текст ошибки с указанием строки в коде пользователя
- Доступно автоматическое форматирование кода в соответствии со стандартами выбранного языка

### 2.4 История решённых задач

- На странице профиля отображается список задач, которые пользователь решил успешно хотя бы один раз
- Для каждой задачи в списке показывается: название, дата первого успешного решения, использованный язык, время выполнения

### 2.5 ИИ-помощник

- В рабочем пространстве задачи доступна кнопка запроса анализа кода
- ИИ получает на вход: текущий код пользователя, выбранный язык, условие задачи и результат последнего запуска (если был)
- По результатам анализа ИИ возвращает:
  - Описание найденных логических ошибок и проблем в коде
  - Советы по улучшению читаемости и структуры без полной переработки
  - Подсказку по направлению решения, не раскрывающую готовый ответ
  - Объяснение того, почему конкретные тест-кейсы не прошли, если код уже запускался
- Результат анализа отображается в отдельной панели рядом с редактором
- ИИ не выдаёт готовый код решения — только направляет рассуждения пользователя

### 2.6 Сообщество

- После успешного решения задачи пользователю становятся доступны принятые решения других участников с фильтрацией по языку программирования
- Пользователь может оставить оценку задаче от 1 до 5 звёзд и написать текстовый отзыв; одна оценка на пользователя на задачу
- Пользователь может подать жалобу на задачу, выбрав причину из списка и при желании добавив пояснительный текст

## 3. Теоретические тесты

### 3.1 Создание теста

- Пользователь заполняет: название теста, описание, тема, уровень сложности
- К тесту добавляются вопросы: текст вопроса, несколько вариантов ответа, указание одного или нескольких правильных
- Поддерживаются два типа вопросов: с одним правильным ответом и с несколькими правильными ответами
- К вопросу можно прикрепить фрагмент кода для наглядности
- Опционально устанавливается ограничение времени на прохождение всего теста в минутах

### 3.2 Просмотр и фильтрация тестов

- Список тестов отображается постранично
- Доступна фильтрация по теме и уровню сложности
- На карточке теста отображается: название, тема, сложность, количество вопросов, ограничение времени (если задано)

### 3.3 Прохождение теста

- Вопросы отображаются последовательно, по одному на экран
- Если задан лимит времени — в интерфейсе показывается обратный отсчёт; по истечении тест завершается автоматически
- До завершения теста пользователь не может видеть правильные ответы
- Пользователь может вернуться к предыдущим вопросам и изменить ответ до финальной отправки

### 3.4 Результаты прохождения

- После отправки отображается итог: процент правильных ответов, количество верных и неверных
- Пользователь видит полный разбор: по каждому вопросу показан выбранный ответ, правильный ответ и пометка верно/неверно

### 3.5 История пройденных тестов

- На странице профиля отображается список всех пройденных тестов
- Для каждого теста показывается: название, дата последнего прохождения, результат в процентах, лучший результат среди всех попыток

## 4. Соревновательный режим (PvP)

### 4.1 Поиск соперника

- Автоматический матчмейкинг: система подбирает соперника из очереди ожидания
- Создание приватной комнаты: пользователь получает код приглашения и передаёт его другу
- Список открытых комнат: отображаются доступные для вступления комнаты с никнеймом создателя

### 4.2 Ход батла

- Перед стартом один из игроков выбирает задачу для сражения
- Оба игрока видят прогресс соперника в реальном времени: сколько тест-кейсов пройдено
- Чат между участниками доступен в течение всего батла
- Игрок может сдаться в любой момент — это засчитывается как поражение
- При разрыве соединения игрок может переподключиться к активному батлу

### 4.3 Завершение батла

- Победителем объявляется первый игрок, прошедший все тест-кейсы задачи
- По итогам батла обоим игрокам начисляется опыт; победителю дополнительно начисляются очки рейтинга

## 5. Панель администратора

> Доступна пользователям с ролью **Администратор**

### 5.1 Модерация задач

- Просмотр полного списка задач на платформе с поиском и фильтрацией
- Редактирование любой задачи: изменение названия, описания, темы, сложности
- Скрытие задачи от публичного доступа без удаления — задача перестаёт отображаться в списке для пользователей
- Удаление задачи вместе со всей связанной историей решений и отзывами

### 5.2 Модерация жалоб

- Список всех поданных жалоб с фильтрацией по статусу (на рассмотрении / принята / закрыта) и по причине
- Просмотр деталей жалобы: автор, задача, причина, дополнительный текст, дата подачи
- Изменение статуса жалобы: администратор переводит жалобу в один из статусов по результатам проверки

## 6. Аналитика (владелец)

> Доступна только **владельцу сайта**

### 6.1 Общий обзор

- KPI-карточки с ключевыми метриками: общее число пользователей, задач, отправок кода, поданных жалоб
- График активности пользователей за выбранный период с возможностью изменить диапазон дат

### 6.2 Аналитика задач

- Распределение задач по темам и по уровням сложности в виде диаграмм
- Распределение решений по языкам программирования
- Топ задач с наименьшим процентом успешных решений
- Воронка вовлечённости: сколько пользователей просмотрели задачу, попробовали решить и решили успешно

### 6.3 Аналитика пользователей

- Таблица топ-пользователей по рейтингу и по накопленному опыту
- Гистограммы распределения пользователей по диапазонам рейтинга и опыта

### 6.4 Аналитика жалоб

- Круговая диаграмма жалоб по статусам: сколько на рассмотрении, принято, закрыто
- Столбчатая диаграмма жалоб по причинам: какие нарушения встречаются чаще всего

### 6.5 Тепловая карта активности

- Визуализация активности пользователей по дням недели и часам суток
- Позволяет определить пиковые периоды нагрузки на платформу
