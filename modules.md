# Модули сайта и их взаимодействие

---

## 1. Модули сайта

### М1 — Модуль аутентификации и авторизации

Отвечает за регистрацию, вход, управление сессиями и контроль доступа по ролям.

- Регистрация и вход по email/паролю
- Вход через Google OAuth2 и GitHub OAuth2
- Выдача и обновление JWT-токенов
- Определение роли пользователя (Пользователь / Администратор / Владелец)
- Защита маршрутов на основе роли

---

### М2 — Модуль задач по программированию

Отвечает за создание, хранение, отображение и выполнение задач.

- Создание и редактирование задач с тест-кейсами
- Верификация задачи перед публикацией
- Список задач с фильтрацией и пагинацией
- Предоставление рабочего пространства (редактор + терминал)
- Автоматическое форматирование кода
- Сохранение результата каждой попытки

---

### М3 — Модуль теоретических тестов

Отвечает за создание, хранение и прохождение теоретических тестов.

- Создание теста с вопросами и вариантами ответов
- Список тестов с фильтрацией
- Интерфейс пошагового прохождения с таймером
- Подсчёт и сохранение результата
- Разбор ошибок после завершения

---

### М4 — Модуль выполнения кода

Отвечает за безопасный запуск пользовательского кода.

- Получение кода, языка и тест-кейсов от модуля задач или соревнований
- Запуск кода в изолированном Docker-контейнере
- Применение ограничений: 128 МБ ОЗУ, без сети, лимит по времени
- Транспиляция TypeScript и CoffeeScript в JavaScript перед запуском
- Компиляция C++, C, C#, Java перед выполнением
- Возврат результатов: статус, вывод, ошибки, время выполнения по каждому тест-кейсу

---

### М5 — Модуль соревновательного режима

Отвечает за организацию PvP-батлов в реальном времени.

- Матчмейкинг: автоматический поиск или приватная комната
- Синхронизация состояния батла между игроками через WebSocket
- Передача задачи и кода в модуль выполнения кода
- Определение победителя и начисление рейтинга/опыта
- Чат между участниками в ходе батла

---

### М6 — Модуль профиля пользователя

Отвечает за отображение личных данных и истории активности.

- Персональная статистика: решённые задачи, пройденные тесты, рейтинг, опыт
- История решённых задач по программированию
- История пройденных теоретических тестов
- Список созданных задач и тестов
- Список поданных жалоб
- Редактирование данных профиля

---

### М7 — Модуль сообщества

Отвечает за взаимодействие пользователей вокруг задач.

- Просмотр принятых решений других пользователей с фильтрацией по языку
- Оценка задачи и написание текстового отзыва
- Подача жалобы на задачу с указанием причины

---

### М10 — Модуль ИИ-помощника

Отвечает за анализ кода пользователя с помощью языковой модели.

- Приём кода, языка и условия задачи от модуля задач
- Отправка запроса к внешнему API языковой модели (Claude API)
- Анализ кода: логические ошибки, качество, структура
- Генерация подсказки по направлению решения без раскрытия ответа
- Объяснение причин провала тест-кейсов на основе вывода выполнения
- Возврат результата анализа в рабочее пространство пользователя

---

### М8 — Модуль администрирования

Отвечает за модерацию контента и пользователей.
Доступен роли **Администратор**.

- Просмотр, редактирование, скрытие и удаление задач
- Просмотр и обработка жалоб: изменение статуса, просмотр деталей

---

### М9 — Модуль аналитики

Отвечает за сбор и визуализацию статистики платформы.
Доступен только **владельцу сайта**.

- Общие KPI: пользователи, задачи, отправки, жалобы
- Активность пользователей за период и тепловая карта
- Статистика задач по темам, сложности, языкам
- Топ-пользователи и распределение по рейтингу/опыту
- Аналитика жалоб по статусам и причинам

---

### Текстовое описание взаимодействий

**М1 и все остальные модули.**
Модуль аутентификации является точкой входа для любого пользователя. После успешного входа он передаёт идентификатор пользователя и его роль во все остальные модули. Именно на основе роли определяется, к каким модулям пользователь имеет доступ: обычный пользователь работает с задачами, тестами, профилем и сообществом; администратор дополнительно получает доступ к модулю администрирования; владелец — к модулю аналитики.

**М2 и М4 — задачи и выполнение кода.**
Когда пользователь нажимает «Запустить» в рабочем пространстве задачи, модуль задач передаёт в модуль выполнения кода три вещи: написанный пользователем код, выбранный язык программирования и набор тест-кейсов. Модуль выполнения запускает код в изолированном Docker-контейнере и возвращает обратно результаты по каждому тесту — статус, вывод программы, текст ошибки и время выполнения. После этого модуль задач отображает результаты в терминальной панели и сохраняет попытку в историю.

**М2 и М10 — задачи и ИИ-помощник.**
Если пользователь запрашивает анализ своего кода, модуль задач передаёт в модуль ИИ-помощника код, язык, условие задачи и, если код уже запускался, результат последнего выполнения. Модуль ИИ-помощника формирует запрос к внешнему API языковой модели и возвращает в рабочее пространство структурированный ответ: описание найденных проблем, советы по улучшению и подсказку по направлению решения без раскрытия готового ответа.

**М2 и М6 — задачи и профиль.**
После каждой успешной отправки модуль задач фиксирует результат в истории пользователя. Модуль профиля затем читает эти данные и отображает список решённых задач, статистику по языкам и общий прогресс.

**М3 и М6 — теоретические тесты и профиль.**
По завершении теста модуль теоретических тестов сохраняет результат прохождения. Модуль профиля читает эти данные и отображает список пройденных тестов с результатами и датами.

**М5 и М4 — соревновательный режим и выполнение кода.**
В ходе батла каждый игрок отправляет своё решение. Модуль соревновательного режима перехватывает этот запрос и направляет код в модуль выполнения так же, как это делает обычный модуль задач. Получив результаты, модуль соревнований через WebSocket транслирует прогресс противника второму игроку и определяет победителя, если все тест-кейсы пройдены.

**М5 и М6 — соревновательный режим и профиль.**
По окончании батла модуль соревнований передаёт итог в модуль профиля: победитель получает очки рейтинга и опыт, проигравший — только опыт.

**М2 и М7 — задачи и сообщество.**
Все действия сообщества привязаны к конкретной задаче. Просмотр чужих решений, написание отзыва и подача жалобы доступны только на странице задачи, поэтому модуль сообщества всегда работает в контексте данных, предоставленных модулем задач.

**М7 и М8 — сообщество и администрирование.**
Когда пользователь подаёт жалобу, она сохраняется и становится доступна в модуле администрирования. Администратор видит жалобу в общем списке, может изучить её детали и изменить статус — рассматривается, принята или закрыта.

**М2, М3, М5, М6, М7 и М9 — все модули и аналитика.**
Модуль аналитики не взаимодействует с пользователями напрямую. Он агрегирует данные из всех остальных модулей: активность из М2 и М3, результаты батлов из М5, статистику пользователей из М6, жалобы из М7. Доступ к этим данным есть только у владельца сайта.
